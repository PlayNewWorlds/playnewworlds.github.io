# playnewworlds.github.io

GitHub Pages host for [The New Worlds](https://github.com/PlayNewWorlds/newworlds).

This repo holds nothing but the built Web (HTML5/WebAssembly) export.
Its contents are fully generated and replaced on every publish by
[newworlds' CI pipeline](https://github.com/PlayNewWorlds/newworlds/blob/master/.github/workflows/ci.yml) —
don't edit anything here directly, it'll be overwritten on the next
push to `newworlds:master`.

Source, tests, and everything else live in
[PlayNewWorlds/newworlds](https://github.com/PlayNewWorlds/newworlds).
